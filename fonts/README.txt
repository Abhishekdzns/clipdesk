Bundled: Geist, Geist Mono, Inter, Manrope (open licences, see each project).
Clip titles and captions are designed for GTA Art Deco (Medium). It is not redistributable, so it is not in this repo.
Put your own title font here (for example GTAArtDeco-Medium.ttf) or change the font name in layouts.py. Without it, Inter is used.
